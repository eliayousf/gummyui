# Local production-build browser evidence

This directory is a continuously refreshed, source-fingerprinted evidence set.
Its name records the date the gate was introduced, not the date of every run.
The JSON `generatedAt` value and checksum manifest identify the current run.

The 28 July 2026 refresh covers the source fingerprint recorded in the JSON and
a local production build. It is automated Chrome evidence only: it does not
claim deployed-origin, Firefox, WebKit, touch-hardware, manual zoom,
screen-reader or founder visual verification. Deployment evidence is recorded
separately in
`docs/audits/production-launch-verification-2026-07-28.md`.
