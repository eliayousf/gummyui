# Changelog

All notable Gummy UI changes are recorded here. Dates use the Europe/London
calendar.

## 1.0.0 — 26 July 2026

### Added

- Stage 3 Group 9: Carousel, Data Table, Direction, Resizable, Scroll Area,
  Table, and Sonner.
- Labelled finite or looping slides, generic typed data operations, native
  table composition, scoped Base UI direction, pointer and keyboard panel
  resizing, native custom-scrollbar viewports, and accessible toast workflows.
- Behaviour, axe, Lab, registry dependency, clean-install, public-ref, RTL,
  reduced-motion, and API documentation coverage.

### Changed

- The live component catalogue now covers all 57 launch categories across all
  nine dependency groups.

## 0.9.0 — 26 July 2026

### Added

- Stage 3 Group 8: Calendar, Combobox, Command, Date Picker, Input Group, Input
  OTP, and Select.
- Locale-aware calendar navigation, Base UI editable and non-editable pickers,
  filterable command actions, composed date selection, grouped native inputs,
  and paste-aware verification-code entry.
- Behaviour, axe, Lab, registry dependency, clean-install, ref-forwarding, and
  API documentation coverage.

## 0.8.0 — 26 July 2026

### Added

- Stage 3 Group 7: Context Menu, Menubar, Navigation Menu, and Sidebar.
- Application-command, site-discovery, and workspace navigation systems with
  native landmarks, current-page state, keyboard focus, typeahead, and
  responsive layout.
- Behaviour, axe, Lab, registry, install-fixture, and API documentation coverage.

## 0.7.0 — 26 July 2026

### Added

- Stage 3 Group 6: Alert Dialog, Drawer, Hover Card, Popover, Sheet, and Tooltip.

- Behaviour, axe, Lab, registry, install-fixture, and API documentation coverage.
