# Catalogue Parity Plan

## Launch definition

“Same as RetroUI” means the same product envelope and catalogue breadth using
original Gummy UI design and implementation. It does not mean copying RetroUI's
component styling, blocks, templates, copy, names, or paid source.

The public launch is not considered complete until the free catalogue reaches
57 documented component categories. The paid launch is not considered complete
until Pro reaches 158 original blocks across 22 categories, six templates, and
the full design kit.
