# Gummy UI social preview — ImageGen 01

Use case: `ads-marketing`

Mode: reference-guided generation using the approved Gummy UI card and Stage 1B component studies.

Prompt:

> Create a landscape social preview image for an open-source React component library called Gummy UI. Use the two supplied reference images only as a material and art-direction reference.
>
> Format: 1200 × 630 landscape marketing card, clean editorial product-design composition, no browser chrome and no device frame.
>
> Exact visible text, and no other text:
> “Gummy UI”
> “Make vibe-coded products feel deliberately designed.”
>
> Show a refined, cohesive Northstar-style software dashboard composition made from connected translucent fruit-gel material: one shared frosted glass reservoir, a raspberry interactive control, grape and lime status capsules, and a calm aqua reading plane. The UI should feel squishy, optically deep, polished, and genuinely usable—not clip art. Shapes must connect through shared edges, shared reservoirs, or obvious functional relationships. Avoid detached decorative circles, random geometric shapes, hard purple outlines, tacky drop shadows, rainbow streaks, and generic pill spam.
>
> Palette: warm milk background, deep aubergine typography, raspberry, grape, lime, and restrained aqua. Lighting: soft studio translucency with internal highlights and subtle refraction. Typography should be large, extremely legible, accurately spelled, and positioned away from the product composition. Premium Swiss editorial layout with generous breathing room.
