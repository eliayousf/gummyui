# Gummy Dropdown Menu — ImageGen prompt 02

Use case: ui-mockup

Asset type: focused production art-direction study for one React Dropdown Menu component

Primary request: Redesign the Gummy UI Dropdown Menu so both the trigger and popup feel unmistakably translucent, tactile, pressure-shaped fruit gel—not a rounded button plus a bordered rectangle. Show four views: closed trigger, open menu, keyboard-highlighted item, and a compact dark-plum comparison. The design must be implementable with layered HTML/CSS while native menu text stays crisp.

Scene/backdrop: warm cream editorial component sheet with a subtle grid; one compact dark-plum strip.

Composition/framing: large close-up study. Closed trigger reads “Sort · Newest”. Open menu rows read “Newest · Selected”, “Oldest”, “Most active”, separator, “Archive project”.

Style/medium: refined high-fidelity product UI material study, selective translucent fruit-gel and frosted warm-milk glass, understated editorial typography.

Color palette: warm milk, translucent grape, a small raspberry danger accent, aubergine ink; aqua only for keyboard focus.

Materials/textures: Trigger is one irregular pressure-shaped milk-glass capsule whose lower-right end thickens into an attached grape reservoir; the chevron is embedded in that thicker end. It should have visible optical depth, internal colour clouding, a small local glint, and an asymmetric silhouette that gently squashes when pressed. Popup is not a rectangular outlined card: it is a calm warm-milky translucent plane held inside one continuous irregular grape-gel membrane. The membrane is thin and nearly absent across most edges, visibly thickens into a lower-right pooled reservoir, has a subtly wavy pressure-shaped top and sides, and transmits the background. Selected/highlighted rows create a soft internal colour tide across part of the reading plane, not a separate pill and not a boxed row. Opening motion should be suggested as the trigger reservoir stretching downward and unfolding into the popup membrane.

Constraints: accessible dark aubergine text in light mode and warm-white text in dark mode; native compact product proportions; menu remains scannable; a single connected gel mass; clear selected and focus states; no browser chrome; no device frame.

Avoid: uniform outlines, blue or purple keyline boxes, generic rounded rectangles, detached corner bubbles, standalone pills, hard drop shadows, bottom shelves, rainbow stripes, metallic chrome, excessive gloss, 2003 clip art, watermark.
