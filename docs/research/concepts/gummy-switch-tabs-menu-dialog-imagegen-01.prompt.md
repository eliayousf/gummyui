# Gummy Switch, Tabs, Dropdown Menu, and Dialog — ImageGen prompt 01

Use case: ui-mockup

Asset type: focused art-direction study for a production React component library

Primary request: Design one cohesive Gummy UI reference sheet for four canonical interaction components: Switch, Tabs, Dropdown Menu, and Dialog. The established system uses selective translucent fruit-gel material, stable warm-milky reading layers, asymmetric pressure-shaped silhouettes, local glints, cloudy internal colour pools, and chewy physical motion. It must look refined and product-ready, never like clip art.

Scene/backdrop: warm cream editorial component sheet with a subtle grid; include a compact dark-plum theme comparison strip.

Composition/framing: landscape component system board. Row 1 Switch states: Off, On, Keyboard focus, Disabled. Row 2 Tabs: Overview selected, Activity, Settings, plus keyboard focus. Row 3 Dropdown Menu: closed trigger and open menu with Newest selected, Oldest, Most active, separator, Archive. Row 4 Dialog: open confirmation modal titled “Archive project?” with body “You can restore it later.” and actions “Keep project” and “Archive”.

Style/medium: high-fidelity product UI art direction, tactile translucent gel and frosted glass, clean editorial typography.

Color palette: raspberry, grape, lime, tangerine, aqua, warm milk, aubergine ink; dark comparison uses deep plum canvas with warm white labels.

Materials/textures: Switch is a compact asymmetric gel track with an attached fruit-glass thumb, not an iOS clone. Tabs share one calm translucent gel rail with selected material pooling under the active tab, not separate pills. Dropdown popup is a warm-milky reading plane held by a thin asymmetric grape/aqua gel edge with a small attached lower corner reservoir. Dialog is a calm frosted plane held by a restrained raspberry gel-pocket perimeter; it is not a giant card and not a giant button. Interactive focus redistributes aqua inside the component rather than drawing an exterior outline.

Constraints: exact component labels where feasible; native-product proportions; stable readable text; distinct hover/focus/selected/disabled states; accessible contrast; no browser chrome; no device frame.

Avoid: perfect pills, generic rounded rectangles, detached bubbles, thick exterior outlines, rainbow lines, hard bottom shelves, obvious drop shadows, metallic chrome, neon cyberpunk, 2003 clip art, excessive gloss, watermark.
